Each thinking/tool step in a bordered card. Green borders for tools, purple for thinking. Emoji icons. Easy to scan.

C — Light Mode + Expandable

Left-border accents. Collapsible tool details (press 'd' to expand). Clean light theme. Professional look.

Key features in all 3:

  • Thinking indicator — spinner + duration + thought snippet while LLM processes
  • Tool step details — tool name, args summary, result preview, timing
  • Input/response boundary — clear visual separator with prompt indicator
  • Formatted output — bold, italic, code blocks, colored file types
