# TUI Chat Interface Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the raw println-based chat REPL with a full Ratatui TUI featuring card-based agent interaction rendering, Markdown output, collapsible thinking/tool steps, and a Ghostty-style theme system.

**Architecture:** New `crates/app-host/src/tui/` module with Ratatui event loop. The app receives `LiveRunEvent` via `tokio::mpsc` channel, renders card-based UI with collapsible thinking (purple) and tool (green) cards, and full Markdown output with syntax-highlighted code blocks. Theme loaded from `~/.zstar/config/tui.toml`.

**Tech Stack:** `ratatui` 0.29, `crossterm` 0.28, `comrak` 0.36, `syntect` 5.2, `toml` 0.8

```rust
pub fn parse_hex_color(hex: &str) -> Option<Color> {
    let hex = hex.trim_start_matches('#');
    if hex.len() != 6 {
        return None;
    }
    let r = u8::from_str_radix(&hex[0..2], 16).ok()?;
    let g = u8::from_str_radix(&hex[2..4], 16).ok()?;
    let b = u8::from_str_radix(&hex[4..6], 16).ok()?;
    Some(Color::Rgb(r, g, b))
}

pub fn load_tui_config(home: &Path) -> (TuiConfig, Theme) {
    let config_path = home.join(".zstar").join("config").join("tui.toml");
    let tui_config: TuiConfig = if config_path.exists() {
        let content = std::fs::read_to_string(&config_path).unwrap_or_default();
        toml::from_str(&content).unwrap_or_default()
    } else {
        TuiConfig::default()
    };

    let theme = load_theme(home, &tui_config.theme);
    (tui_config, theme)
}

fn load_theme(home: &Path, name: &str) -> Theme {
    let builtin = match name {
        "github-dark" => Some(include_str!("themes/github_dark.toml")),
        "tokyo-night" => Some(include_str!("themes/tokyo_night.toml")),
        "light" => Some(include_str!("themes/light.toml")),
        _ => None,
    };

    if let Some(content) = builtin {
        let config: ThemeConfig = toml::from_str(content).unwrap();
        return Theme::from_config(&config);
    }

    let custom_path = home.join(".zstar").join("themes").join(format!("{name}.toml"));
    if custom_path.exists() {
        let content = std::fs::read_to_string(&custom_path).unwrap_or_default();
        if let Ok(config) = toml::from_str::<ThemeConfig>(&content) {
            return Theme::from_config(&config);
        }
    }

    Theme::github_dark()
}
```

```rust
use syntect::highlighting::ThemeSet;
use syntect::parsing::SyntaxSet;

pub struct SyntaxHighlighter {
    syntax_set: SyntaxSet,
    theme_set: ThemeSet,
    theme_name: String,
}

impl SyntaxHighlighter {
    pub fn new(theme_name: &str) -> Self {
        let syntax_set = SyntaxSet::load_defaults_newlines();
        let theme_set = ThemeSet::load_defaults();
        Self {
            syntax_set,
            theme_set,
            theme_name: theme_name.to_string(),
        }
    }

    pub fn highlight(&self, code: &str, language: Option<&str>) -> Vec<(syntect::highlighting::Style, &str)> {
        let syntax = match language {
            Some(lang) => self.syntax_set.find_syntax_by_token(lang),
            None => self.syntax_set.find_syntax_by_first_line(code),
        };

        let syntax = match syntax {
            Some(s) => s,
            None => match self.syntax_set.find_syntax_plain_text() {
                Some(s) => s,
                None => return vec![(syntect::highlighting::Style::default(), code)],
            },
        };

        syntect::highlighting::highlight_lines(code, syntax, &self.theme_set.themes[&self.theme_name])
            .unwrap_or_else(|_| vec![(syntect::highlighting::Style::default(), code)])
    }

    pub fn syntect_style_to_ratatui(
        style: syntect::highlighting::Style,
    ) -> ratatui::style::Style {
        let fg = syntect_color_to_ratatui(style.foreground);
        ratatui::style::Style::default()
            .fg(fg)
            .add_modifier(if style.font_style.contains(syntect::highlighting::FontStyle::BOLD) {
                ratatui::style::Modifier::BOLD
            } else if style.font_style.contains(syntect::highlighting::FontStyle::ITALIC) {
                ratatui::style::Modifier::ITALIC
            } else {
                ratatui::style::Modifier::empty()
            })
    }
}

fn syntect_color_to_ratatui(color: syntect::highlighting::Color) -> ratatui::style::Color {
    ratatui::style::Color::Rgb(color.r, color.g, color.b)
}
```

```rust
pub mod syntax;

use ratatui::style::{Color, Modifier, Style};
use ratatui::text::{Line, Span};

use crate::tui::theme::Theme;

pub struct StyledLine(pub Vec<(Style, String)>);

pub fn parse_markdown(input: &str, theme: &Theme) -> Vec<StyledLine> {
    let mut lines = Vec::new();
    let arena = comrak::Arena::new();
    let root = comrak::parse_document(&arena, input, &comrak::Options::default());

    for node in root.children() {
        render_node(node, &mut lines, theme);
    }

    lines
}

fn render_node<'a>(
    node: &'a comrak::nodes::AstNode<'a>,
    lines: &mut Vec<StyledLine>,
    theme: &Theme,
) {
    use comrak::nodes::NodeValue;

    match &node.data.borrow().value {
        NodeValue::Heading(heading) => {
            let style = Style::default()
                .fg(theme.heading)
                .add_modifier(Modifier::BOLD);
            let text = collect_text(node);
            let prefix = "#".repeat(heading.level as usize) + " ";
            lines.push(StyledLine(vec![(style, format!("{prefix}{text}"))]));
        }
        NodeValue::Paragraph => {
            let spans = collect_inline_spans(node, theme);
            lines.push(StyledLine(spans));
            lines.push(StyledLine(vec![(Style::default(), String::new())]));
        }
        NodeValue::CodeBlock(code) => {
            let lang = if code.info.is_empty() {
                None
            } else {
                Some(code.info.as_str())
            };
            let highlighter = syntax::SyntaxHighlighter::new(&theme.syntax_theme);
            let highlighted = highlighter.highlight(&code.literal, lang);
            for (style, text) in highlighted {
                let rat_style = syntax::SyntaxHighlighter::syntect_style_to_ratatui(style);
                let bg_style = rat_style.bg(theme.code_bg);
                lines.push(StyledLine(vec![(bg_style, text.to_string())]));
            }
            lines.push(StyledLine(vec![(Style::default(), String::new())]));
        }
        NodeValue::List(_list_type) => {
            for (i, child) in node.children().enumerate() {
                let prefix = format!("  {}. ", i + 1);
                let mut spans = vec![(Style::default().fg(theme.foreground), prefix)];
                spans.extend(collect_inline_spans(child, theme));
                lines.push(StyledLine(spans));
            }
        }
        NodeValue::BlockQuote => {
            for child in node.children() {
                let mut inner = collect_inline_spans(child, theme);
                let mut quoted = vec![(Style::default().fg(theme.border), "│ ".into())];
                quoted.append(&mut inner);
                lines.push(StyledLine(quoted));
            }
            lines.push(StyledLine(vec![(Style::default(), String::new())]));
        }
        NodeValue::ThematicBreak => {
            lines.push(StyledLine(vec![(
                Style::default().fg(theme.border),
                "─".repeat(40),
            )]));
        }
        _ => {
            let spans = collect_inline_spans(node, theme);
            if !spans.is_empty() {
                lines.push(StyledLine(spans));
            }
        }
    }
}

fn collect_inline_spans<'a>(
    node: &'a comrak::nodes::AstNode<'a>,
    theme: &Theme,
) -> Vec<(Style, String)> {
    use comrak::nodes::NodeValue;
    let mut spans = Vec::new();

    for child in node.children() {
        match &child.data.borrow().value {
            NodeValue::Text(text) => {
                spans.push((Style::default().fg(theme.foreground), text.clone()));
            }
            NodeValue::Code(code) => {
                spans.push((
                    Style::default().fg(theme.code_fg).bg(theme.code_bg),
                    code.literal.clone(),
                ));
            }
            NodeValue::Strong => {
                let inner = collect_text(child);
                spans.push((Style::default().fg(theme.bold).add_modifier(Modifier::BOLD), inner));
            }
            NodeValue::Emph => {
                let inner = collect_text(child);
                spans.push((Style::default().fg(theme.italic).add_modifier(Modifier::ITALIC), inner));
            }
            NodeValue::Link(link) => {
                let text = collect_text(child);
                spans.push((Style::default().fg(theme.link).add_modifier(Modifier::UNDERLINED), text));
            }
            NodeValue::SoftBreak | NodeValue::LineBreak => {
                spans.push((Style::default(), " ".into()));
            }
            _ => {
                spans.extend(collect_inline_spans(child, theme));
            }
        }
    }

    spans
}

fn collect_text<'a>(node: &'a comrak::nodes::AstNode<'a>) -> String {
    use comrak::nodes::NodeValue;
    let mut result = String::new();
    for child in node.children() {
        match &child.data.borrow().value {
            NodeValue::Text(text) => result.push_str(text),
            _ => result.push_str(&collect_text(child)),
        }
    }
    result
}

pub fn styled_lines_to_ratatui(styled: &[StyledLine]) -> Vec<Line> {
    styled
        .iter()
        .map(|StyledLine(spans)| {
            Line::from(
                spans
                    .iter()
                    .map(|(style, text)| Span::styled(text.clone(), *style))
                    .collect::<Vec<_>>(),
            )
        })
        .collect()
}
```

- [ ] **Step 1: Create event.rs**

```rust
use crossterm::event::{Event as CrosstermEvent, EventStream, KeyCode, KeyEvent};
use futures_util::StreamExt;

use crate::live_runtime::LiveRunEvent;

pub enum AppEvent {
    Key(KeyEvent),
    Agent(LiveRunEvent),
    Tick,
}

pub async fn read_events(
    agent_rx: &mut tokio::sync::mpsc::Receiver<LiveRunEvent>,
) -> AppEvent {
    tokio::select! {
        maybe_event = agent_rx.recv() => {
            match maybe_event {
                Some(event) => AppEvent::Agent(event),
                None => AppEvent::Tick,
            }
        }
        maybe_event = EventStream::new().next() => {
            match maybe_event {
                Some(Ok(event)) => AppEvent::Key(match event {
                    CrosstermEvent::Key(key) => key,
                    _ => return AppEvent::Tick,
                }),
                _ => AppEvent::Tick,
            }
        }
    }
}
```

- [ ] **Step 2: Create app.rs**

`ChatApp` struct (as defined in spec) with `update(app_event)` and `draw(frame)` methods.

`ResponseBlock` enum:
```rust
pub enum ResponseBlock {
    UserPrompt { text: String },
    ThinkingCard { duration: Option<std::time::Duration>, content: Option<String>, collapsed: bool },
    ToolCard { name: String, args_summary: String, result: Option<String>, duration: Option<std::time::Duration>, expanded: bool, is_error: bool },
    MarkdownContent { parsed: Vec<crate::tui::markdown::StyledLine> },
}
```

`update()` handles:
- `AppEvent::Key(Enter)` → send input to agent, add `UserPrompt` block, start thinking
- `AppEvent::Key(Char('d'))` → toggle expand on last tool/thinking card
- `AppEvent::Key(Ctrl('c'))` → quit
- `AppEvent::Agent(LiveRunEvent)` → match on `event.kind`:
  - `message_started` → add ThinkingCard
  - `message_delta` → accumulate markdown content
  - `tool_call_started` → add ToolCard
  - `tool_execution_completed` → finalize ToolCard
  - `message_completed` → finalize MarkdownContent, flush accumulated text
  - `run_completed` → stop thinking
- `AppEvent::Key(PageUp/PageDown)` → scroll

`draw()` renders:
- Clear frame with theme background
- ResponseList in main area
- InputBar at bottom (fixed 3-line height)
- Scroll indicator if scrolled up
