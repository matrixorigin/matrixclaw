Bootstrap contract

Target surface: http://127.0.0.1:38495/setup or http://127.0.0.1:38495/workspace

  1. Reach the local runtime boundary
  2. Decide whether setup or workspace should open
  3. Hand the same app window to MatrixClaw

Product boundary

The shell owns startup polish, window continuity, and attach feedback. The runtime still owns setup, sessions, tools, and execution behavior.

Failure posture

If the loopback surface is unavailable, the window stays in a readable bootstrap state instead of dumping the user into a raw network error.
